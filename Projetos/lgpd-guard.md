# lgpd-guard

Firewall de dados pessoais para LLMs: detecta e pseudonimiza CPF, CNPJ, cartão, nomes; proxy compatível com a API da OpenAI.

**Números (fonte: README do repositório):** F1 0,94 (regras + NER) contra 0,60 do Presidio no conjunto desafio; 94,4% dos textos protegidos.
