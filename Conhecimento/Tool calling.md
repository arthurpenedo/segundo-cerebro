# Tool calling

**O que é:** O modelo não executa nada: ele pede para chamar uma função com argumentos, e o código decide se executa.

**Onde usei:** [[agente-banco]]: a regra de estorno até R$ 100 fica dentro da ferramenta, não no prompt.
